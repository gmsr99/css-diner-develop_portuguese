Não te preocupes, tu consegues!

Vais aprender seletores CSS! Os seletores servem para escolher os elementos a que queres aplicar estilos.

Exemplo 1 - Uma regra CSS

p {
   margin-bottom: 12px;
}

Aqui, o "p" é o seletor (seleciona todos os elementos <p>) e aplica-lhes o estilo margin-bottom.

Para jogar, escreve um seletor CSS no editor abaixo para selecionares os itens certos da mesa. Se acertares, passas ao nível seguinte.

Passa o rato sobre os itens da mesa para veres o respetivo código HTML.

Os nomes da comida estão em português e sem acentos (a maçã é <maca>), mas as palavras do próprio CSS, como :first-child, são sempre em inglês.
